# Dental Disease Detection System with Chatbot Assistant

This project was fully developed and implemented by **Abdelkhalek Soudy** in 2025.

## ?? Overview
A complete AI-based dental diagnosis system, which includes:
- Deep learning YOLOv8 model for dental disease detection.
- Medical chatbot using LLaMA model for interactive dental advice.
- React frontend with secure image upload and multilingual disease explanation.
